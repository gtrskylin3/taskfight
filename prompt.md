# app: TaskFight 
Я хочу сделать приложение основная идея которого объединить в себе todo list focus timer и добавить элементы гемификации

Что я хочу видеть:

основой будет todo list
Task будет иметь 
- name
- priority
- tag 
- timer
тоесть у меня есть задача например решать квадратные уравнения по математике 2 часа и я создаю 
Task(
    name=Решать квадратные уравнения
    priority=High # выбор low medium high
    tag = Математика
    timer = 120 # в минутах
)
я создал задачу она допустим показывается на главной странице я могу начать её выполнение кликнув start возле 
что тогда начнется:
создаётся timer с временем 2 часа и тикает пока не закончится его можно приостановить нажав pause также можно её закончить раньше времени нажав stop либо complete 
то-есть у нас есть 3 сценария:

end - задача завершается и добавляется в выполненные

stop - значить засчитать прогресс выполнения тоесть на главной появится полоска типо хп задачи где написано сколько процентов осталось и в конце этой полоски время нужное для выполнение 

complete - значит что ты считаешь задачу выполненой раньше времени при нажатии задача завершается и добавляется в выполненные

также будет гемифицированый dashboard со статистикой 
где можно будет отслеживать:

- общее время в задачах каждого tag с фильтром по 
день/неделя/месяц/год/все время

- выполненные задачи по каждому тегу с фильтром 
день/неделя/месяц/год/всевремя и фильтром по приоритету 
high/low/medium

Как нужно реализовать:
это будет веб приложение со следующим стеком

backend асинхронный на python: 
fastapi, 
sqlalchemy+postgresql 
если нужно будет то (redis, celery)

frontend минималистичный стильный в dark стиле: 

главная страница это todo page в ней по стандарту расположены задачи на текущий день отсортированные по убыванию приоритета
их можно сортировать по тегу например только по математике будут показываться  
можно выбрать in progress где будут невыполненные задачи у которых полоска хп не на нуле не забудь её реализовать:
полоска типо хп задачи где написано сколько процентов осталось и в конце этой полоски время нужное для выполнение

для задачи по кнопке start можно запустить таймер который динамически заменит страницу главной на минималистичный черный экран где:
- показывается оставшееся время в формате через :
сверху показывается полоска хп текущей задачи 
снизу кнопки pause stop complete


в хедере на главной можно будет перейти на гемифицированый dashboard со статистикой где можно будет отслеживать:

- общее время в задачах каждого tag с фильтром по 
день/неделя/месяц/год/все время

high/low/medium
